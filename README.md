# Neon Chomp

A fast, glowing maze-chase game for the browser. Clear the maze, dodge the Glitches, overcharge
and bite back. Pick your own colours.

## Play

```
python3 -m http.server 8000
```
Open http://localhost:8000.

**Controls:** arrows/WASD to move · Space to dash · P to pause
